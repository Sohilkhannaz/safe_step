Password safety guide

Make account access harder to guess

Think of a password as a key. A longer, unique key for each account makes it harder for one exposed password to unlock everything.

  • ✓
    Choose long and unique

    Use a long passphrase or password that is different for each account.

  • ✓
    Avoid easy guesses

    Skip names, birthdays, school names, common words, and predictable patterns.

  • ✓
    Consider a reputable password manager

    It can create and remember different passwords. Protect it with a strong master password and MFA where available.

  • ✓
    Enable multi-factor authentication (MFA)

    MFA asks for another proof of identity, such as an authenticator approval, in addition to your password.

  • ✓
    Act if a password is exposed

    Change it on that service and anywhere else you reused it. Use the official service, not a link in an alert.

  • ✓
    Keep secrets to yourself

    Never share passwords, OTPs, or recovery codes, even with someone claiming to be support.

✦

A passphrase idea

Join several unrelated words to make a longer phrase that is memorable to you. Avoid famous quotes or personal facts others could guess.

Example pattern: word-word-word-word
