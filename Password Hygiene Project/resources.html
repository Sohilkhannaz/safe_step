Frequently asked questions

Is a password manager safe to use?

A reputable manager can help you create and remember unique passwords. Research the provider, protect the manager account, and enable MFA if offered.

Should I change my password often?

Change it promptly if it may have been exposed, if you shared it, or if the service advises you to. Avoid predictable routine changes that only alter one character.

What if I clicked a suspicious link?

Do not enter details. If you did, use the official service to change the affected password, enable MFA, and contact the service through a trusted channel.

Is public Wi-Fi always unsafe?

Not always, but a network may not be trustworthy. Avoid sensitive actions when unsure and use your mobile connection when available.
